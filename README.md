💭 Práticando pilares da Programação Orientada a Objetos
Esse repositório foi criado com o intuito de relembrar e praticar conceitos importantes da Programação Orientada a Objetos usando o Java.
O projeto foi dividido em alguns packges, e dentro de cada packge existe uma pasta domain e outra pasta main. O intuito não era construir nada complexo ou mais elaborado, mas sim relembrar os conceitos e como eles funcionam na prática.
